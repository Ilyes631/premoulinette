Rules

Authorized builtins:

  • input()
  • print()
  • len()
  • int()
  • str()
  • float()
  • bool()

Forbidden builtins: abs(), max(), min(), round(), sorted(), sum(), eval().

No import is allowed.

Your functions must return their result: they must not print anything. Files containing functions must not execute any code when they are imported (no debug print left at the top level).

Exercise 3 — Landing grade

File: MysteryInc/FirstLaunch/flight_functions/grade_landing.py

def landing_grade(vertical_speed: int) -> str:

Grade the landing according to the vertical speed (in m/s):

  • vertical_speed <= 2 → "Perfect touchdown"
  • 2 < vertical_speed <= 5 → "Hard landing"
  • vertical_speed > 5 → "Crash!"
>>> landing_grade(1)
'Perfect touchdown'
>>> landing_grade(4)
'Hard landing'
>>> landing_grade(9)
'Crash!'

Exercise 4 — Fuel share

File: MysteryInc/FirstLaunch/route_math/fuel_share.py

def fuel_share(total_fuel: int, crew: int) -> int:
def remaining_fuel(total_fuel: int, crew: int) -> int:

fuel_share returns the amount of fuel each crew member receives: total_fuel // crew. remaining_fuel returns what is left in the tank once the fuel has been shared: total_fuel % crew. You can assume crew > 0.

>>> fuel_share(400, 3)
133
>>> remaining_fuel(400, 3)
1
>>> fuel_share(500, 3)
166

Exercise 5 — Mission clock

File: MysteryInc/FirstLaunch/route_math/mission_clock.py

def mission_clock(seconds: int) -> str:

Return the duration formatted as HH:MM:SS, each field on two digits: f"{seconds // 3600:02}:{seconds % 3600 // 60:02}:{seconds % 60:02}".

>>> mission_clock(3725)

>>> mission_clock(0)
'00:00:00'
